# Xây dựng website đặt phòng khách sạn
## Giới thiệu đề tài
Đây là đồ án xây dựng website đặt phòng khách sạn nhằm hỗ trợ khách hàng tra cứu thông tin phòng, đặt phòng trực tuyến và hỗ trợ quản lý khách sạn một cách hiệu quả.
Hệ thống giúp số hóa quy trình quản lý phòng, khách hàng, đặt phòng và thanh toán.
