## 🚀 Công nghệ sử dụng

### Frontend (Giao diện người dùng)
* **HTML & CSS:** Xây dựng cấu trúc và định dạng giao diện.
* **Bootstrap :** Hỗ trợ thiết kế Responsive (tương thích đa thiết bị).
* **JavaScript & jQuery:** Xử lý tương tác, hiệu ứng và các yêu cầu AJAX.

### Backend (Xử lý máy chủ)
* **ASP.NET Core MVC:** Mô hình phát triển ứng dụng web mạnh mẽ.
* **C#:** Ngôn ngữ lập trình chính.

### Cơ sở dữ liệu
* **Microsoft SQL Server:** Hệ quản trị cơ sở dữ liệu quan hệ (RDBMS).

## 🛠️ Hướng dẫn cài đặt

1. **Cơ sở dữ liệu:**
   - Mở **SQL Server Management Studio (SSMS)**.
   - Chạy file script `.sql` (đính kèm trong thư mục Database) để tạo cấu trúc bảng và dữ liệu mẫu.

2. **Cấu hình kết nối:**
   - Mở dự án trong **Visual Studio 2022**.
   - Tìm file `Web.config` hoặc `appsettings.json`.
   - Chỉnh sửa dòng `ConnectionString` để khớp với Server Name của SQL Server trên máy bạn.

3. **Chạy dự án:**
   - Nhấn `F5` hoặc nút **Start** trên Visual Studio để khởi động website trên trình duyệt Chrome/Edge.
